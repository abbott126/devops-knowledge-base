K8s 基础命令

k8s 管理命令 kubectl

Kubernetes provides a command line tool for communicating with a Kubernetes cluster's control plane, using the Kubernetes API.

语法：

kubectl [command] [TYPE] [NAME] [flags]

帮助手册：

kubectl  --help
kubectl  [command] --help

获取集群中所有节点

命令： kubectl get

示例：

[root@master ~]# kubectl  get nodes  
NAME     STATUS   ROLES           AGE     VERSION
master   Ready    control-plane   3h58m   v1.31.13
work01   Ready    <none>          3h25m   v1.31.13
work02   Ready    <none>          3h24m   v1.31.13
work03   Ready    <none>          3h24m   v1.31.13
#可以使用别名
[root@master ~]# kubectl  get no
字段 语义
NAME 节点的域名/主机名
STATUS 节点的状态 Ready/NoReady
ROLES 角色：标识节点的作用
AGE 运行时间
VERSION k8s 的版本

获取节点详细信息

[root@master ~]# kubectl   get  nodes -o  wide

字段 语义
INTERNAL-IP 内部IP 集群内部通信
EXTERNAL-IP 外部IP loadblence
OS-IMAGE
CONTAINER-RUNTIME
KERNEL-VERSION

指定查看节点信息

[root@master ~]# kubectl   get  node master
NAME     STATUS   ROLES           AGE     VERSION
master   Ready    control-plane   4h32m   v1.31.13

获取所有的Pod

[root@master ~]# kubectl  get pods  
No resources found in default namespace.

默认会在default名称空间下找资源对象

-A: 所有名称空间下的Pod

[root@master ~]# kubectl  get pods -A
NAMESPACE     NAME                 READY   STATUS    RESTARTS       AGE
kube-system   calico-kube          1/1     Running   0              150m
字段 语义
NAMESPACE 名称空间，作用应用隔离，环境隔离
NAME Pod 名称
READY Pod 是否准备完成 1/1 1/1
STATUS Pod的运行状态
RESTARTS 重启次数
AGE Pod 的运行时间

查看Pod 运行在那个节点上

[root@master ~]# kubectl   get pods  -A  -o wide

字段 语义
NOMINATED NODE 指定节点（Pod）亲和性
READINESS GATES 就绪状态

指定某个名称空间的pod

[root@master ~]# kubectl  get  pods  -n kube-system

查看名称：

[root@master ~]# kubectl  get namespace
NAME              STATUS   AGE
default           Active   4h36m
kube-node-lease   Active   4h36m
kube-public       Active   4h36m
kube-system       Active   4h36m

查看Pod的详细信息：

语法：kubectl describe [资源类型] [资源的名称] [名称空间]

[root@master ~]# kubectl   describe  pods calico-node-rt5h7  -n kube-system

查看版本：

[root@master ~]# kubectl   version
Client Version: v1.31.13
Kustomize Version: v5.4.2
Server Version: v1.31.13

查看集群状态：

[root@master ~]# kubectl   cluster-info

查看所有的api 资源

[root@master ~]# kubectl  api-resources

查看API 的版本信息

[root@master ~]# kubectl   api-versions
admissionregistration.k8s.io/v1
