Secrets 密钥

A Secret is an object that contains a small amount of sensitive data such as a password, a token, or a key. Such information might otherwise be put in a Pod specification or in acontainer image. Using a Secret means that you don't need to include confidential data in your application code.
秘密对象是指包含少量敏感数据的对象，例如： 密码、令牌或密钥。此类信息也可能被放入……Pod 规格或在 容器镜像 。使用密钥意味着您无需在应用程序代码中包含机密数据。

由于 Secret 的创建可以独立于使用它们的 Pod，因此在创建、查看和编辑 Pod 的工作流程中，Secret（及其数据）泄露的风险更低。Kubernetes 以及在集群中运行的应用程序还可以对 Secret 采取额外的预防措施，例如避免将敏感数据写入非易失性存储。

警告：

默认情况下，Kubernetes Secret 以未加密的形式存储在 API 服务器的底层数据存储（etcd）中。任何拥有 API 访问权限的用户都可以检索或修改 Secret，任何拥有 etcd 访问权限的用户也可以这样做。此外，任何被授权在命名空间中创建 Pod 的用户都可以使用该权限读取该命名空间中的任何 Secret；这包括间接访问，例如创建 Deployment 的权限

创建 ex-secrets.yaml

apiVersion: v1
kind: Secret
metadata:
  name: dotfile-secret
data:
  .secret-file: cm9vdEAxMjMK

生成密码文件: 十进制文件 --> 二进制

命令：base64

[root@master ~]# echo  "root@123" | base64
cm9vdEAxMjMK
[root@master ~]# echo  "cm9vdEAxMjMK"  | base64 -d
root@123

案例：

以下是结合 db-secret 密钥创建 Redis Pod 的完整配置，实现通过密码（密码）登录 Redis 的功能。配置中会从 Secret 中读取 Redis 密码，并通过环境变量注入到容器中，确保密码安全存储和使用。

实现步骤：创建一个密钥文件

首先确保之前创建的 db-secret 已存在（若不存在，先执行创建命令）

[root@master security]# kubectl get secret db-secret

编译yaml文件redis-secret.yaml

apiVersion: v1
kind: Secret
metadata:
  name: db-secret
type: Opaque
data:
  db-user: cmVkaXNhZG1pbg==      # 编码后的用户名（redisadmin）
  db-password: cmVkaXNAMTIz      # 编码后的密码（redis@123）

创建secret

[root@master redis-example]# ka  -f redis-secret.yaml

编辑一个redis-pod示例文件

# redis-pod.yaml
apiVersion: v1
kind: Pod
metadata:
  name: redis-with-secret
spec:
  containers:
  - name: redis
    image: redis:latest
    ports:
    - containerPort: 6379
    # 从 Secret 中读取环境变量（用户名和密码）
    env:
    - name: REDIS_USER       # 自定义环境变量名（Redis 用户名）
      valueFrom:
        secretKeyRef:
          name: db-secret    # 引用的 Secret 名称
          key: db-user       # Secret 中的键（用户名）
    - name: REDIS_PASSWORD   # 自定义环境变量名（Redis 密码）
      valueFrom:
        secretKeyRef:
          name: db-secret
          key: db-password   # Secret 中的键（密码）
    # 启动 Redis 时配置密码认证（通过命令行参数）
    command: ["redis-server", "--requirepass", "$(REDIS_PASSWORD)"]
    # 可选：挂载 Secret 为文件（如需通过文件读取密码）
    volumeMounts:
    - name: secret-volume
      mountPath: /etc/redis/secret
      readOnly: true  # 只读挂载，增强安全性
  # 定义 Secret 卷（用于文件挂载方式）
  volumes:
  - name: secret-volume
    secret:
      secretName: db-secret  # 关联 db-secret

创建Pod

[root@master redis-example]# ka  -f redis-pod.yaml

等待Pod 创建完成之后验证： 进入redis的Pod

部署Dashboard管理k8s 集群

基于web

  • 官方： Dashboard

  • 第三方： kabor

基于桌面

  • Lens

创建用户及角色绑定 admin-user.yaml

apiVersion: v1
kind: ServiceAccount
metadata:
  name: admin-user
  namespace: kubernetes-dashboard

创建角色admin-role-binding.yaml

apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRoleBinding
metadata:
  name: admin-user
roleRef:
  apiGroup: rbac.authorization.k8s.io
  kind: ClusterRole
  name: cluster-admin
subjects:
- kind: ServiceAccount
  name: admin-user
  namespace: kubernetes-dashboard

创建

kubectl  apply -f  .

获取token

kubectl -n kubernetes-dashboard create token admin-user
