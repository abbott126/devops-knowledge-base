kubernetes 的包管理器

Helm 是 Kubernetes 生态中最核心的包管理器，它能将 Kubernetes 应用的所有资源（如 Deployment、Service、ConfigMap 等）打包成统一的 “Chart”，实现应用的快速部署、版本管理、升级与回滚，极大简化了 K8s 应用的运维流程。

一、Helm 的核心价值：解决 K8s 应用管理痛点

在没有 Helm 时，部署一个复杂 K8s 应用（如 Nginx + MySQL + Redis）需要手动编写多个 YAML 文件，存在以下问题：

  1. 资源分散：一个应用对应多个 YAML（Deployment、Service 等），管理和分发困难；
  2. 版本混乱：应用升级 / 回滚时，需手动修改多个 YAML 版本，易出错；
  3. 环境适配差：开发 / 测试 / 生产环境的配置（如数据库地址、资源配额）需手动替换，效率低。

Helm 通过以下特性解决这些问题：

  • Chart 打包：将应用所有资源和配置模板打包成 “Chart”，可跨集群复用；
  • 版本控制：为每个应用版本生成 “Release”（部署实例），支持一键升级、回滚；
  • 配置模板化：通过 “Values.yaml” 分离配置与模板，支持不同环境动态注入配置（如 --set env=prod）。

二、Helm 的核心概念

Helm 3 之后移除了中心化的 “Tiller” 组件，架构更轻量，核心概念有 3 个：

概念 含义
Chart 应用的 “安装包”，包含应用的所有 K8s 资源模板（YAML）和配置模板（Values.yaml），可存储在本地或远程仓库（如 Helm Hub）。
Release Chart 部署到 K8s 集群后的 “实例”，每个 Chart 可多次部署（如部署 nginx-dev 和 nginx-prod 两个 Release），每个 Release 有独立版本。
Repository Chart 的 “仓库”，用于存储和分发 Chart（类似 Docker Hub），支持公开仓库（如 Artifact Hub）或私有仓库。

三、安装 helm 命令

官方文档：https://helm.sh/zh/docs/intro/install/

用二进制版本安装

每个Helm版本都提供了各种操作系统的二进制版本，这些版本可以手动下载和安装。

  1. 下载需要的版本
  2. 解压(tar -zxvf helm-v3.0.0-linux-amd64.tar.gz)
  3. 在解压目录中找到helm程序，移动到需要的目录中(mv linux-amd64/helm /usr/local/bin/helm)

测试是否可以使用helm

[root@master linux-amd64]# helm
The Kubernetes package manager

Common actions for Helm:

- helm search:    search for charts
- helm pull:      download a chart to your local directory to view
- helm install:   upload the chart to Kubernetes
- helm list:      list releases of charts

子命令的帮助：

[root@master ~]# helm  repo --help 
  add         add a chart repository
  index       generate an index file given a directory containing packaged charts
  list        list chart repositories
  remove      remove one or more chart repositories
  update      update information of available charts locally from chart repositories

三、Helm 3 常用命令（核心操作）

Helm 命令遵循 “helm 子命令 [参数]” 格式，以下是日常高频操作：

1. 基础配置：添加仓库

先添加公开仓库（如官方 Nginx 仓库），才能拉取 Chart：

# 添加 Nginx 官方 Chart 仓库
[root@master ~]# helm repo add nginx-stable https://helm.nginx.com/stable 
# 更新仓库
[root@master ~]# helm  repo  update  nginx-stable
# 列出仓库
[root@master ~]# helm  repo list 
NAME            URL                          
nginx-stable    https://helm.nginx.com/stable
  1. 安装应用：nginx
[root@master ~]# helm  search  repo nginx-stable
NAME                                            CHART VERSION   APP VERSION     DESCRIPTION                                      
nginx-stable/nginx-appprotect-dos-arbitrator    0.2.0           1.2.0           NGINX App Protect Dos Arbitrator                 
nginx-stable/nginx-devportal                    1.7.2           1.7.2           A Helm chart for deploying ACM Developer Portal 

[root@master ~]# helm  install  {name} nginx-stable/nginx-ingress  --generate-name

安装 Helm Chart 时必须提供一个 Release 名称，或者通过 --generate-name 让 Helm 自动生成名称。

  1. 安装traefik
[root@master traefik]# helm install my-release stable/traefik --namespace kube-system
