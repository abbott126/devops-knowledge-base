ansible.builtin.file 模块 –

描述：管理文件和文件属性

概要：

  • 设置文件、目录或符号链接的属性及其目标。
  • 或者，删除文件、符号链接或目录
  • 许多其他模块支持与 ansible.builtin.file 模块相同的选项，包括 ansible.builtin.copy、ansible.builtin.template 和 ansible.builtin.assemble。
  • 对于 Windows 目标，请改用 ansible.windows.win_file 模块

Ex: 创建文件

[root@ansible-server ~]# ansible all  -m file -a "path=/opt/a state=touch"
192.168.1.103 | CHANGED => {
    "ansible_facts": {
        "discovered_interpreter_python": "/usr/bin/python"
    }, 
    "changed": true, 
    "dest": "/opt/a", 
    "gid": 0, 
    "group": "root", 
    "mode": "0644", 
    "owner": "root", 
    "secontext": "unconfined_u:object_r:usr_t:s0", 
    "size": 0, 
    "state": "file", 
    "uid": 0
}
[root@ansible-server ~]# ansible  all  -m file  -a "path=/opt/b state=directory"

group 模块

描述： Add or remove groups

Example: 创建组

[root@ansible-server ~]# ansible  all  -m  group  -a "name=dev01 state=present"

Example: 移除组

[root@ansible-server ~]# ansible  all  -m  group  -a "name=dev01 state=absent"

package 模块

描述：通用作系统包管理器 ；不指定如何系统包管理命令比如ubunut-->apt redhat-->yum|dnf

Example:

[root@ansible-server ~]# ansible  web   -m package -a  "name=httpd state=present" -vv

YUM/DNF 模块

描述：使用 dnf 包管理器管理包；

概要：

  • 使用 dnf 包管理器安装、升级、删除和列出包和组。

  • Aliases: yum

Example: 安装

[root@ansible-server ~]# ansible  web  -m yum  -a "name=vsftpd   state=latest"
[root@ansible-server ~]# ansible web -m yum -a "name=httpd state=installed"
#指定安装包所在的位置
[root@ansible-server ~]# ansible web -m yum  -a "name=https://nginx.org/packages/rhel/7Server/x86_64/RPMS/nginx-1.26.1-2.el7.ngx.x86_64.rpm state=latest"

验证：适用Shell模块

[root@ansible-server ~]# ansible web  -m shell -a "rpm -q vsftpd"
[WARNING]: Consider using the yum, dnf or zypper module rather than running 'rpm'.  If you need to use command
because yum, dnf or zypper is insufficient you can add 'warn: false' to this command task or set
'command_warnings=False' in ansible.cfg to get rid of this message.
192.168.1.103 | CHANGED | rc=0 >>
vsftpd-3.0.2-28.el7.x86_64
192.168.1.105 | CHANGED | rc=0 >>
vsftpd-3.0.2-28.el7.x86_64

Example: absent removed

[root@ansible-server ~]# ansible web -m yum -a "name=vsftpd state=absent"
[root@ansible-server ~]# ansible web -m yum -a "name=httpd state=removed"
