Git 版本控制系统的工作原理

  1. 克隆远程到本地
  2. 将本地的工作文件，暂存区；提交本地仓库
  3. 推送到远程仓库
  4. 拉去远程仓库到本地

!image-20250917105836144](/images/image-20250917105836144.png)

初始化一个本地仓库 git init

abbott@abbott:~$ git  init  test

查看仓库的状态

abbott@abbott:~/test$ git status

添加到暂存区

abbott@abbott:~/test$ git add . # 将工作区的所有文件添加到暂存区中

输出结果：

!image-20250917110621846](/images/image-20250917110621846.png)

提交到本地仓库中

abbott@abbott:~/test$ git commit -m "udate abc  bc file"

第一次提交作者及联系方式

abbott@abbott:~/test$ git config --global user.email "abbott68@126.com"
abbott@abbott:~/test$ git config --global user.name "abbott68"

验证：

abbott@abbott:~/test$ git status  
On branch master
nothing to commit, working tree clean

查看日志（代码提交日志）

abbott@abbott:~/test$ git log  
commit 6a92514ef2cab14959347cceb912a32a736af1ce (HEAD -> master)
Author: abbott68 <abbott68@126.com>
Date:   Wed Sep 17 03:12:58 2025 +0000

    update abc

commit 71344eb906427cb14c0eef46aaa19e8e72659de8
Author: abbott68 <abbott68@126.com>
Date:   Wed Sep 17 03:08:32 2025 +0000

    udate abc  bc file

重置HEAD

abbott@abbott:~/test$ git  reset 71344eb9064
Unstaged changes after reset:
M   abc

回退到原来的初始版本

abbott@abbott:~/test$ git  restore abc

分支:

作用： 需要每个功能创建一个分支；实现协同开发；还可以实现每个分支的隔离；请求主分支

创建分支

abbott@abbott:~/test$ git  branch  dev01
abbott@abbott:~/test$ git  branch  dev02
abbott@abbott:~/test$ git  branch  dev03

查看分支

abbott@abbott:~/test$ git branch 
  dev01
  dev02
  dev03
* master #你所在的分支

切换分支：

abbott@abbott:~/test$ git  switch dev01
Switched to branch 'dev01'
abbott@abbott:~/test$ git branch 
* dev01
  dev02
  dev03
  master

删除分支：

abbott@abbott:~/test$ git branch   -D  dev02
Deleted branch dev02 (was 71344eb).
abbott@abbott:~/test$ git branch  -l 
* dev01
  dev03
  master

合并分支：

git  merge

私有仓库 gitlab

Gitlab 概述：

代码管理仓库；

支持企业版和社区版

支持GitOps CI/CD

部署

gitlab部署要求：

  • 需要一台Linux主机 unix/Linux 子系统
  • 内存 >=4
  • 存储 >=20
  • cpu >=2

redhat 8 install

https://docs.gitlab.com/install/package/almalinux/

install gitlab-ce

  1. 添加防火墙规则(关闭可以略过)

Ubuntu

  1. shell sudo systemctl enable --now sshsudo ufw allow 22/tcp sudo ufw allow 80/tcp sudo ufw allow 443/tcp sudo ufw enable

  2. Redhat

sudo systemctl enable --now sshd
sudo firewall-cmd --permanent --add-service=http
sudo firewall-cmd --permanent --add-service=https
sudo firewall-cmd --permanent --add-service=ssh
sudo systemctl reload firewalld

安装gitlab-ce 源

  • ubuntu
curl "https://packages.gitlab.com/install/repositories/gitlab/gitlab-ce/script.deb.sh" | sudo bash
  • Redhat 
curl "https://packages.gitlab.com/install/repositories/gitlab/gitlab-ce/script.rpm.sh" | sudo bash

安装gitlab-ce

Ubuntu 

sudo apt install gitlab-ce

redhat

sudo dnf install gitlab-ce
sudo dnf  install  --download-only  gitlab-ce
