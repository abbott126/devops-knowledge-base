Docker compose

Docker Compose 是一个用于定义和运行多容器 Docker 应用程序的工具。它使用 YAML 文件来配置应用程序的服务、网络、数据卷等，然后通过一个简单的命令就能启动整个应用栈。

核心概念

  • 单机编排：主要针对单台主机上的多容器应用
  • 声明式配置：使用 YAML 文件描述整个应用架构
  • 一键操作：一条命令启动/停止所有服务

主要配置项

配置项 说明 示例
version Compose 文件版本 '3.8'
services 定义各个服务容器 web, db, cache
networks 自定义网络配置 backend, frontend
volumes 数据卷配置 db_data, app_logs

Example:

[root@docker httpd-example]# cat   docker-compose.yaml 
version: v1
services:
  web:
    build: .   #当前目录必须有Dockerfile
    ports:
      - "33000:80"

dockercompose命令：

[root@docker httpd-example]# docker compose --help
[root@docker httpd-example]# docker compose  up    #构建并前台运行
[root@docker httpd-example]# docker compose  up -d  #构建完成并后台运行
[root@docker httpd-example]# docker compose  stop  #停止所有的容器（docker-compose.yaml）
[root@docker httpd-example]# docker compose  start #运行所有的容器（docker-compose.yaml）

Harbor

Harbor 是一个开源镜像仓库，它通过策略和基于角色的访问控制来保护工件，确保镜像经过扫描且无漏洞，并将镜像签名为可信镜像。Harbor 是一个 CNCF 毕业项目，提供合规性、性能和互操作性，帮助您在 Kubernetes 和 Docker 等云原生计算平台上一致且安全地管理工件。

Network ports 网络端口

Port 港口 Protocol 协议 Description 描述
443 HTTPS Harbor portal and core API accept HTTPS requests on this port. You can change this port in the configuration file. Harbor 门户和核心 API 在此端口接受 HTTPS 请求。您可以在配置文件中更改此端口。
80 HTTP Harbor portal and core API accept HTTP requests on this port. You can change this port in the configuration file. Harbor 门户和核心 API 在此端口接受 HTTP 请求。您可以在配置文件中更改此端口。

案例：docker compose

[root@docker harbor]# tar  xf  harbor-offline-installer-v2.14.0.tgz   -C /usr/local/

修改配置文件

[root@docker harbor]# cp  harbor.yml.tmpl  harbor.yml
