SQL 语言

SQL（Structured Query Language，结构化查询语言）是用于管理关系型数据库（如 MySQL、Oracle、PostgreSQL）的标准编程语言，核心功能包括数据查询、插入、更新、删除，以及数据库结构的创建、修改和权限控制。它是关系型数据库的 “通用接口”，无论是开发、运维还是数据分析，都需掌握其基础语法与逻辑。

一、SQL 的核心定位与特点

  1. 非过程化语言
    只需描述 “要做什么”（如 “查询用户表中年龄大于 30 的数据”），无需指定 “怎么做”（如数据遍历顺序、底层存储读取逻辑），底层执行计划由数据库管理系统（DBMS）自动优化。
  2. 通用性强
    几乎所有关系型数据库（MySQL、Oracle、SQL Server、PostgreSQL 等）都支持 SQL，语法规则高度统一（核心语法无差异），仅在高级功能（如存储过程、函数）上存在少量 “方言”（如 MySQL 的LIMIT、Oracle 的ROWNUM）。
  3. 功能全面
    覆盖数据库全生命周期操作：从数据读写（DQL/DML）、结构定义（DDL），到事务控制（TCL）、权限管理（DCL），一站式满足关系型数据库的管理需求。
  4. 面向集合操作
    SQL 的操作对象和结果都是 “数据集合”（如一张表、一个查询结果集），而非单条数据，例如UPDATE users SET age=age+1 WHERE city='Beijing'可一次性更新符合条件的所有记录。

二、SQL 的四大核心分类

根据功能不同，SQL 可分为四大类，每类对应特定的数据库操作场景：

分类简称 全称 核心作用 常用命令示例
DQL Data Query Language 数据查询（从数据库中获取数据） SELECT
DML Data Manipulation Language 数据操纵（插入、更新、删除数据） INSERT、UPDATE、DELETE
DDL Data Definition Language 数据定义（创建 / 修改 / 删除数据库对象） CREATE、ALTER、DROP
DCL Data Control Language 数据控制（权限管理、事务控制） GRANT、REVOKE、COMMIT

此外，还有TCL（Transaction Control Language，事务控制语言） ，常被归为 DCL 的子集，核心命令为COMMIT（提交事务）、ROLLBACK（回滚事务）、SAVEPOINT（设置事务保存点）。

关键差异说明

  1. 精度限制：
  2. FLOAT 在存储超过 7 位有效数字时会四舍五入（如第 3 行的 0.000123456789 被近似为 0.000123457）
  3. DOUBLE 能更精确地保留更多位数（如同样的值保留到 0.000123456789）
  4. 自定义精度：
  5. 格式 FLOAT(M, D) 或 DOUBLE(M, D) 中，M 是总位数，D 是小数位数
  6. 例如 FLOAT(10, 4) 表示最多 10 位数字，其中 4 位是小数（如 12345.6789）

适用场景

  • 使用 FLOAT：对精度要求不高的场景（如温度、湿度等物理量），节省存储空间
  • 使用 DOUBLE：需要高精度的场景（如金融计算、科学实验数据）

DECIMAL

语法： CREATE USER '用户名'@'客户端的IP地址' IDENTIFIED BY '*password*';

#限制网段
mysql> create user 'test'@'192.168.19.%' identified  by  'Test@123.';
Query OK, 0 rows affected (0.00 sec)

#不限制
mysql> create  user  'test01'@'%' identified  by 'Test@123.';
Query OK, 0 rows affected (0.01 sec)
#指定客户端地址
mysql> create  user 'test02'@'192.168.1.100' identified  by 'Test@123.';
Query OK, 0 rows affected (0.01 sec)
  • 查询用户的信息mysql.user
mysql> select * from  mysql.user  where User='test'\G;
  • 删除用户
mysql> drop  user  'test'@'192.168.19.%';
Query OK, 0 rows affected (0.01 sec)

权限管理：

  • 赋予权限

命令：grant [all|insert|delete|...] on [库名.*｜所有*.*] to 'user_name'@'客户端地址'

mysql> grant all on *.* to  test@'192.168.19.%';
Query OK, 0 rows affected (0.01 sec)

mysql> grant  select  on db.* to 'test01'@'%';
Query OK, 0 rows affected (0.01 sec)
  • 回收权限
mysql> REVOKE insert on *.*  from 'test01'@'%';
Query OK, 0 rows affected (0.00 sec)

mysql> select * from  mysql.user  where User='test01'\G;
*************************** 1. row ***************************
                    Host: %
                    User: test01
             Select_priv: Y
             Insert_priv: N
mysql> REVOKE drop,delete  on *.*  from 'test01'@'%';
