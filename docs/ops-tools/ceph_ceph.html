    注释：

    列名 含义
    NAME 服务名称（容器 / 应用组件）
    PORTS 暴露的端口（如果有的话）
    RUNNING 当前运行数量 / 期望数量（如果不相等，说明服务未完全启动或异常）
    REFRESHED 最后一次状态刷新时间
    AGE 服务运行时长
    PLACEMENT 部署位置策略（count:N 表示集群中共部署 N 个实例，* 表示所有节点都部署）
