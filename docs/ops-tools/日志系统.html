!image-20250926095147136](/images/image-20250926095147136.png)Logstash

Logstash 是一个开源服务器端数据处理管道，它从多个来源获取数据，对其进行转换，然后将其发送到您最喜欢的“存储”。

Inputs, filters & outputs

Logstash 可以动态地提取、转换和传输您的数据，无论其格式或复杂程度如何。使用 Grok 从非结构化数据中提取结构，从 IP 地址中解析地理坐标，匿名化或排除敏感字段，并简化整体处理。

input 提取各种形状、大小和来源的数据

数据通常以多种格式分散或孤立地分布在多个系统中。Logstash 支持多种输入方式 ，可同时从多个常见来源提取事件。您可以轻松地从日志、指标、Web 应用程序、数据存储和各种 AWS 服务中提取数据，并且全部以连续、流式传输的方式进行。

filter 即时解析和转换您的数据

当数据从源传输到存储时，Logstash 过滤器会解析每个事件，识别命名字段以构建结构，并将它们转换为通用格式，以实现更强大的分析和商业价值。

Output 选择您的存储，传输您的数据

虽然 Elasticsearch 是我们首选的输出，它为我们打开了搜索和分析的可能性，但它并不是唯一可用的。

Logstash 配置错误：ssl_certificate_verification 已过时

你遇到的错误是因为 Logstash 8.x 版本中，ssl_certificate_verification 参数已被废弃，需要使用新的参数 ssl_verification_mode。

  # 系统日志发送到系统数据流

      data_stream_dataset => "system"
      data_stream_namespace => "production"

  else if [type] == "nginx-access" {
    elasticsearch {
      hosts => ["192.168.1.118:9200"]
      data_stream => true
      data_stream_type => "logs"
      data_stream_dataset => "nginx"
      data_stream_namespace => "production"
    }
  }
  stdout { codec => rubydebug }
}
