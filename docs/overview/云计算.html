云计算

一、云计算的基本概念

云计算是一种基于互联网的计算模式，它通过将大量的计算资源（包括服务器、存储、网络、软件等）进行整合并集中部署在数据中心，然后以服务的形式提供给用户使用。用户无需关心这些资源的具体物理位置、底层架构以及运维管理等细节，只需通过网络按需获取所需的计算能力、存储空间、软件应用等资源，并按照使用量或时长来支付相应费用，就如同使用水电等公共服务一样便捷。

安装KVM

安装操作系统

  • 基于图形管理（webui、virt-manager）
  • 基于命令行(自动化安装可以结合脚本)
virt-install \
--memory 2048 \
--vcpus 1 \
--os-variant rhel7 \
--disk path="/opt/vm",size="10",format=qcow2 \
--cdrom  /opt/ISO/rhel-server-7.9-x86_64-dvd.iso

KVM 虚拟化常用命令

命令: virsh

描述： management user interface

语法：virsh [options]... [<command_string>]

KVM 网络

默认：

只有一中网络default NAT

桥接: 在宿主机上通过方式创建网络

仅主机： 自定义文件 后缀名.xml

[root@kvm-server ~]# cat host-only.xml 
<network>
  <name>host-only</name>
</network>

定义网络

[root@kvm-server ~]# virsh  net-define  host-only.xml 
[root@kvm-server ~]# virsh  net-start   host-only
[root@kvm-server ~]# virsh   net-autostart  --network host-only

创建自定以nat网络

[root@kvm-server ~]# cat 18-nat.xml 
<network>
  <name>18nat</name>
  <forward mode='nat'>
    <nat>
      <port start='1024' end='65535'/>
    </nat>
  </forward>
  <bridge name='virbr2' stp='on' delay='0'/>
  <ip address='192.168.18.1' netmask='255.255.255.0'>
    <dhcp>
      <range start='192.168.18.2' end='192.168.18.253'/>
    </dhcp>
  </ip>
</network>

创建网络

[root@kvm-server ~]# virsh  net-define  18-nat.xml 
[root@kvm-server ~]# virsh  net-start   18-nat.xml
[root@kvm-server ~]# virsh   net-autostart  18-nat.xml

查看网络

[root@kvm-server ~]# virsh   net-list  
 名称        状态   自动开始   持久
-------------------------------------
 18nat       活动   是         是
 default     活动   是         是
 host-only   活动   是         是
