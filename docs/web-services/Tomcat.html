二、什么使用使用Tomcat

  1. 如果是使用springboot框架 开发 就不能使用Tomcat发布
  2. 测试环境会使用Tomcat 内存溢出(使用)
  3. 微服务不能Tomcat
  4. 自动化任务(可能)

#临时变量

临时变量：

在现有终端上配置变量

[root@tomcat-server jdk-17.0.16]# #临时
[root@tomcat-server jdk-17.0.16]# export  JAVA_HOME=/usr/local/java/jdk-17.0.16/
[root@tomcat-server jdk-17.0.16]# export  PATH=$PATH:$JAVA_HOME/bin
[root@tomcat-server jdk-17.0.16]# java

局部变量:

创建普通用户配置环境变量

创建用户

[root@tomcat-server ~]# useradd  abbott
[root@tomcat-server ~]# passwd abbott
# 创建用户且加入wheel组
[abbott@tomcat-server ~]$ sudo useradd  test  -G wheel
[abbott@tomcat-server ~]$ passwd  test 
passwd：只有根用户才能指定用户名。
[abbott@tomcat-server ~]$ sudo  passwd  test

授予可以调用sudo的权限(修改配置文件 /etc/sudoers)

## Allow root to run any commands anywhere 
root    ALL=(ALL)       ALL
abbott  ALL=(ALL)       ALL

## Allows people in group wheel to run all commands
%wheel  ALL=(ALL)       ALL

配置局部变量：

[abbott@tomcat-server ~]$ cat .bashrc 
# .bashrc

# Source global definitions
if [ -f /etc/bashrc ]; then
    . /etc/bashrc
fi

# Uncomment the following line if you don't like systemctl's auto-paging feature:
# export SYSTEMD_PAGER=

# User specific aliases and functions
export  JAVA_HOME=/usr/local/java/jdk-17.0.16/
export  PATH=$PATH:$JAVA_HOME/bin

[abbott@tomcat-server ~]$ source  .bashrc   #加载/刷新配置

[abbott@tomcat-server ~]$ java

   或  java [options] -jar <jar 文件> [args...]
           （执行 jar 文件）

管理Tomcat

用户可以访问8005端口

  1. 修改context.xml 允许客户端使用IP地址请求8005端口；默认仅限于127.0.0.1
[root@tomcat-server logs]# find  /  -name  context.xml
/usr/local/tomcat/tomcat10/conf/context.xml
/usr/local/tomcat/tomcat10/webapps/docs/META-INF/context.xml
/usr/local/tomcat/tomcat10/webapps/examples/META-INF/context.xml
/usr/local/tomcat/tomcat10/webapps/host-manager/META-INF/context.xml
/usr/local/tomcat/tomcat10/webapps/manager/META-INF/context.xml



#依次将上面检索`context.xml`关于修改将127的地址修改"^.*$"
[root@tomcat-server tomcat10]# cat /usr/local/tomcat/tomcat10/webapps/manager/META-INF/context.xml | grep allow
         allow="^.*$" />
[root@tomcat-server tomcat10]# 

#重启服务

!image-20250820115437939](/images/image-20250820115437939.png)

  1. 配置用户/角色和密码
[root@tomcat-server tomcat10]# cat  conf/tomcat-users.xml 
<tomcat-users xmlns="http://tomcat.apache.org/xml"
              xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
              xsi:schemaLocation="http://tomcat.apache.org/xml tomcat-users.xsd"
              version="1.0">
  <role rolename="manager-gui"/>
  <user username="tomcat" password="tomcat" roles="manager-gui"/>
  <role rolename="admin-gui"/>
  <user username="tomcat" password="tomcat" roles="admin-gui"/>
</tomcat-users>

发布应用 Java：

java应用都会构建为.jar || .war 包

  1. 利用Tomcat发布应用
  2. 是用Java命令管理应用

利用Tomcat发布应用

案例： jenkins

获取地址： https://www.jenkins.io

!image-20250820152152134](/images/image-20250820152152134.png)

第二种方案：

直接将应用的war包推送到webapps目录下

[root@tomcat-server tomcat10]# cd webapps/
[root@tomcat-server webapps]# ls
docs  examples  host-manager  jenkins  jenkins.war  manager  ROOT
[root@tomcat-server webapps]# pwd
/usr/local/tomcat/tomcat10/webapps

使用Java命令管理应用

#语法
[root@tomcat-server local]# java  -jar  *.war  || *.jar

#前台运行
[root@tomcat-server local]# java -jar jenkins.war 
Running from: /usr/local/jenkins.war
webroot: /root/.jenkins/war
# 后台运行并且输出日志
[root@tomcat-server local]# nohup  java -jar jenkins.war   &  
[1] 9763

查看后台运行的进程

[root@tomcat-server local]# jobs   #查看后台运行或者停止的任务
[1]-  运行中               nohup java -jar jenkins.war &
[2]+  已停止               vim abc


#将后台的任务调度到前台运行
[root@tomcat-server local]# fg  [后台任务的编号]

# 查看Java应用的进程命令
[root@tomcat-server local]# jps  
9763 war

分析：

jps 常与其他 Java 工具（如 jstat、jmap、jstack 等）配合使用，用于 Java 应用程序的监控和问题排查。
