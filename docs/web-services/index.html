依次安装软件包

对于源码部署：（口诀三板斧）

1. 检查环境
./configure
2. 编译
make
3. 编译安装
make install
  • apr
[root@web-server apr-1.7.6]# ./configure  --prefix=/usr/local/apache1/apr
[root@web-server apr-1.7.6]#  make 
[root@web-server apr-1.7.6]#  make install

判断上次执行的命令是否成功： echo $?

0 # 非0 表示执行失败

  • apr-util
[root@web-server apr-util-1.6.3]# ./configure  --prefix=/usr/local/apache1/apr-util   --with-apr=/usr/local/apache1/apr
[root@web-server apr-util-1.6.3]# make
[root@web-server apr-util-1.6.3]# make install

--prefix= # 指定安装目录

--with-apr= # 指定apr安装的位置

  • httpd
[root@web-server httpd-2.4.65]# ./configure \
--prefix=/usr/local/apache1/http/ \
--with-apr=/usr/local/apache1/apr \
--with-apr-util=/usr/local/apache1/apr-util/
[root@web-server httpd-2.4.65]# make 
[root@web-server httpd-2.4.65]# make install

正向代理

正向代理是客户端（如个人电脑、手机）的 “中间人”，代表客户端向目标服务器发起请求。客户端需主动配置代理地址，所有请求先发送到代理服务器，再由代理转发至目标服务器，最终将服务器响应回传给客户端。

反向代理

反向代理是服务器（如 Web 服务器、应用服务器）的 “中间人”，代表服务器接收客户端的请求。客户端无需配置代理，只需向 “代理服务器” 发送请求（以为代理就是目标服务器），代理再根据规则将请求转发到后端真实的服务器集群，最终将后端响应回传给客户端。

Nginx 负载均衡器（LB load balancer）

Nginx 负载均衡是通过 Nginx 作为反向代理服务器，将客户端请求合理分配到后端多台服务器，以实现流量分散、提高系统吞吐量和可用性的技术。它是高并发场景下（如电商、短视频平台）保障服务稳定的核心手段。

一、负载均衡的核心作用

  1. 分流减压：避免单台服务器因请求过多而过载（如秒杀活动的流量峰值）。
  2. 高可用：某台后端服务器故障时，自动将请求转发到其他正常服务器，减少服务中断。
  3. 扩展灵活：通过增加后端服务器数量，线性提升系统处理能力（无需修改客户端配置）。

二、 配置负载均衡
