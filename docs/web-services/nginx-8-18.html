正向代理

正向代理是客户端（如个人电脑、手机）的 “中间人”，代表客户端向目标服务器发起请求。客户端需主动配置代理地址，所有请求先发送到代理服务器，再由代理转发至目标服务器，最终将服务器响应回传给客户端。

反向代理

反向代理是服务器（如 Web 服务器、应用服务器）的 “中间人”，代表服务器接收客户端的请求。客户端无需配置代理，只需向 “代理服务器” 发送请求（以为代理就是目标服务器），代理再根据规则将请求转发到后端真实的服务器集群，最终将后端响应回传给客户端。

Nginx 负载均衡器（LB load balancer）

Nginx 负载均衡是通过 Nginx 作为反向代理服务器，将客户端请求合理分配到后端多台服务器，以实现流量分散、提高系统吞吐量和可用性的技术。它是高并发场景下（如电商、短视频平台）保障服务稳定的核心手段。

一、负载均衡的核心作用

  1. 分流减压：避免单台服务器因请求过多而过载（如秒杀活动的流量峰值）。
  2. 高可用：某台后端服务器故障时，自动将请求转发到其他正常服务器，减少服务中断。
  3. 扩展灵活：通过增加后端服务器数量，线性提升系统处理能力（无需修改客户端配置）。

二、 配置负载均衡

Nginx 调度算法

  • rr. 轮询调度算法
  • least-connected 最少连接算法
  • ip-hash 基于客户端的 源IP 地址；请求到后端节点上

Example：

默认轮询

upstream web-server {
     server 192.168.18.20;
     server 192.168.18.30;
}

最少连接

upstream web-server {
     least_conn;
     server 192.168.18.20;
     server 192.168.18.30;
}

Ip_hash

upstream web-server {
     ip_hash;
     server 192.168.18.20;
     server 192.168.18.30;
}

加权轮询算法：

upstream web-server {
     server 192.168.18.20 weight=3;
     server 192.168.18.30;
}

上课示例

[root@nginx-proxy nginx128]# cat   conf/vhosts/upstream.conf 
upstream web-server {
     server 192.168.18.20  max_fails=3  fail_timeout=30s;
     server 192.168.18.30  max_fails=3  fail_timeout=30s;
     server 192.168.18.30:81 backup;
     #server 192.168.18.30:81 down;
}

server {
    listen 80;

    location / {
        proxy_pass http://web-server;
    }
}

参数描述：

max_fails=3    # 最多允许3次失败
fail_timeout=30s;  # 失败后30秒内不再分配请求
backup;  #当所有的猪节点都失效之后备用节点上线

私有证书

使用openssl 命令创建私有证书

openssl genrsa -out private.key 2048

openssl req -new -key private.key -out certificate.csr

# 生成自签名证书，有效期 365 天
openssl x509 -req -days 365 -in certificate.csr -signkey private.key -out certificate.crt

配置Nginx 

mkdir /usr/local/nginx128/key
mv  certificate.crt private.key   /usr/local/nginx128/key/

开启nginx 的443

    server {
        listen       443 ssl;
        server_name  localhost;

        ssl_certificate      /usr/local/nginx128/key/certificate.crt;
        ssl_certificate_key  /usr/local/nginx128/key/private.key;

        ssl_session_cache    shared:SSL:1m;
        ssl_session_timeout  5m;

        ssl_ciphers  HIGH:!aNULL:!MD5;
        ssl_prefer_server_ciphers  on;

        location / {
            root   html;
            index  index.html index.htm;
        }
    }
